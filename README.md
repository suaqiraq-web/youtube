# بوت يوت تيليجرام

بوت لمجموعة تيليجرام يدعم:

- `يوت اسم الأغنية`: ينزّل الأغنية ويرسلها كملف صوتي فقط داخل المجموعة.
- يجب أن يكون `cookies.txt` بصيغة Netscape وموجودًا بجانب `bot.py` لتجاوز تحقق YouTube عند الحاجة.
- يتم اختيار أخف مصدر صوت وتنزيله بأجزاء متوازية، ثم ضغطه إلى 64 kbps أحادي القناة بدون معالجة metadata لتقليل وقت التنزيل والرفع.
- `الاوامر`: يعرض الأوامر المناسبة للمستخدم؛ الأعضاء يرون الأوامر العادية، والمشرفون يرون جميع الأوامر.
- `شغل اسم الأغنية`: للمشرفين فقط، يبحث عن الأغنية ويشغلها في المكالمة الصوتية.
- `توقف` و`غني` و`تخطي`: أوامر تحكم نصية للمشرفين فقط أثناء تشغيل الحساب المساعد للأغنية.
- `اوكف`: لإيقاف الأغنية مؤقتًا، ويمكن أيضًا استخدام `/pause` و`/resume` و`/skip` و`/stop`.

## التشغيل

1. ثبّت Python 3.11 أو 3.12 أو 3.13، وثبّت FFmpeg وأضفه إلى `PATH`. مكتبة المكالمات الصوتية لا توفر `tgcalls` متوافقًا مع Python 3.14 حاليًا.
2. ثبّت الاعتمادات:

   ```powershell
   py -m pip install -r requirements.txt
   ```

3. انسخ `.env.example` إلى `.env` وضع `BOT_TOKEN`.
4. لتفعيل المكالمة الصوتية، ضع `API_ID` و`API_HASH`، ثم أضف جلسات الحسابات المساعدة في `SESSION_STRINGS` وافصل بينها بفاصلة أو سطر جديد. يمكنك إضافة أي عدد من الجلسات، وسيجربها البوت بالترتيب.
5. أضف البوت إلى المجموعة ومنح جميع الحسابات المساعدة صلاحية الانضمام إلى المكالمة.
6. يخصص البوت حسابًا مساعدًا مستقلًا لكل مجموعة؛ لذلك يمكن تشغيل مكالمتين في مجموعتين دون أن يغلق أحدهما الآخر.
7. عند استخدام `شغل` يحاول البوت إنشاء رابط دعوة مؤقت وإدخال الحسابات المساعدة تلقائيًا، أو تحاول الحسابات الانضمام إذا كانت المجموعة عامة. يجب أن يكون البوت مشرفًا مع صلاحية دعوة المستخدمين.
8. من `@BotFather` استخدم `/setprivacy` ثم اختر البوت واختر `Disable` حتى يستطيع الأعضاء استخدام `يوت اسم الأغنية` داخل المجموعة.
9. شغّل:

   ```powershell
   py bot.py
   ```

عند النشر على Railway، يجب أن يستخدم المشروع ملف `Dockerfile` حتى يتم تثبيت Deno وملحقات yt-dlp اللازمة لاستخراج YouTube.

إذا لم تُضف بيانات الحساب المستخدم، سيعمل البحث وإرسال الروابط، بينما تبقى أوامر المكالمة معطلة.
